
# Personal Portfolio Website

## 📌 Project Overview

This project is a **Personal Portfolio Website** created as part of the **Oasis Infobyte Web Development & Designing Internship – Level 1, Task 2**.

The portfolio website presents my profile, skills, projects, and contact information in a clean and responsive design.

## 🎯 Objective

The objective of this project is to create a personal portfolio website that works as a digital résumé and showcases my technical skills, projects, and professional information.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (if used)

## ✨ Features

* Responsive navigation bar
* Profile/Hero section
* About Me section
* Skills section
* Projects section
* Contact section
* Smooth navigation between sections
* Responsive design for desktop and mobile screens
* Consistent color scheme and typography
* User-friendly interface
