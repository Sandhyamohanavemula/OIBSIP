# Temperature Converter Website

## 📌 Project Overview

This project is a **Temperature Converter Website** created as part of the **Oasis Infobyte Web Development & Designing Internship – Level 1, Task 3**.

The website allows users to enter a temperature value, select the input unit, and convert it into Celsius, Fahrenheit, and Kelvin.

## 🎯 Objective

The objective of this project is to create a simple and user-friendly temperature conversion tool using HTML, CSS, and JavaScript.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Numeric temperature input
- Celsius, Fahrenheit, and Kelvin unit selection
- Temperature conversion between units
- Displays results with appropriate unit labels
- Convert button for performing conversions
- Validation for invalid or non-numeric input
- Handles temperatures below absolute zero
- Clean and centered user interface
- Responsive design for different screen sizes
